# ApsnyGO (АпсныГО) 🌴🏡

> **Веб-агрегатор жилья и отдыха в Республике Абхазия**  
> Стек: Next.js (App Router), React, TypeScript, Tailwind CSS, Google Fonts (Plus Jakarta Sans & Outfit).

---

## 🎨 Дизайн-система и цветовая палитра

Проект оформлен в эстетичной светлой теме, вдохновленной субтропической природой, чистым морем и горами Абхазии:

| Компонент палитры | Код / Название | Классы Tailwind | Описание |
|---|---|---|---|
| **Белый фон** | `#FFFFFF` | `bg-white`, `bg-background` | Чистая светлая основа, простор и свежесть |
| **Мягкая поверхность** | `#F8FAF8`, `#F1F4F1` | `bg-stone-gray-50`, `bg-background-surface` | Контрастные светлые карточки и плашки |
| **Зеленый (Green)** | `#16A34A` / `#15803D` | `text-green-600`, `bg-green-600`, `shadow-green-glow` | Цвет пальм, эвкалиптов и мандариновых садов |
| **Цвет мха (Moss)** | `#586F3E` / `#748D54` | `text-moss-600`, `bg-moss-600`, `border-moss-200` | Бархатистый лесной мох самшитовых рощ и озера Рица |
| **Каменный серый (Stone Gray)** | `#62665D` / `#20221E` | `text-stone-gray-900`, `border-stone-gray-200` | Известняковые скалы каньонов, прибрежная галька, дольмены |

## 🔤 Шрифты (Google Fonts)

Подключены современные геометрические шрифты:
- **`Outfit`** (`var(--font-outfit)`) — выразительный заголовочный гротеск (`font-heading`, `font-outfit`).
- **`Plus Jakarta Sans`** (`var(--font-plus-jakarta)`) — эргономичный, легко читаемый шрифт для основного интерфейса, карточек и фильтров (`font-sans`, `font-jakarta`).

Подключение выполнено через `next/font/google` (с нулевым сдвигом макета Layout Shift и автоматической предзагрузкой) + резервный `link` в `<head>` для Google Fonts.

## 🚀 Запуск проекта

Убедитесь, что установлен Node.js (v18+), затем выполните:

```bash
# Установка зависимостей (уже выполнена в проекте)
npm install

# Запуск локального сервера разработки
npm run dev

# Сборка продакшн-версии
npm run build

# Запуск собранного проекта
npm start
```

Сервер будет доступен по адресу: `http://localhost:3000`.
