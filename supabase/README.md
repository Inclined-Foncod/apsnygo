# Инструкция по подключению базы данных Supabase для ApsnyGO

Этот каталог содержит готовый SQL-код и схемы для развертывания базы данных веб-агрегатора жилья **ApsnyGO** на платформе [Supabase](https://supabase.com).

---

## 🛠️ Шаг 1. Создание проекта в Supabase

1. Зарегистрируйтесь или войдите в [Supabase](https://supabase.com).
2. Нажмите **"New project"** (Создать новый проект).
3. Укажите:
   - **Name**: `ApsnyGO`
   - **Database Password**: придумайте и сохраните надежный пароль.
   - **Region**: выберите ближайший (например, `Frankfurt / Central EU`).
4. Нажмите **"Create new project"** и дождитесь 1-2 минуты, пока база инициализируется.

---

## 📄 Шаг 2. Применение SQL-схемы

1. В левом меню Supabase перейдите в раздел **SQL Editor** (иконка терминала/SQL).
2. Нажмите **"New query"** (Новый запрос).
3. Скопируйте всё содержимое файла `supabase/schema.sql` из нашего проекта.
4. Вставьте в окно редактора Supabase и нажмите зеленую кнопку **"Run"** (Запустить).
5. Вы увидите сообщение `Success. No rows returned`.

### Что будет создано:
- Таблицы: `profiles`, `destinations` (курорты с координатами на карте), `properties` (жилье), `bookings` (брони), `reviews` (отзывы), `favorites` (избранное).
- Enums: типы жилья, роли пользователей, статусы бронирований.
- **RLS (Row Level Security)**: политики безопасности (публичное чтение каталога, приватность личных данных и избранного).
- **Seed Data**: готовые 8 курортов Абхазии с процентами координат для интерактивной карты (Гагра, Пицунда, Сухум, Новый Афон, озеро Рица, Цандрипш, Гудаута, Очамчыра/Кындыг).
- Автоматический триггер для связки регистрации пользователей Supabase Auth с таблицей профилей.

---

## 🔑 Шаг 3. Получение ключей и подключение к сайту

1. В панели управления Supabase перейдите в **Project Settings** (иконка шестеренки внизу слева) -> раздел **API**.
2. Скопируйте два значения:
   - **Project URL** (вида `https://xxxxxxxxxxxx.supabase.co`)
   - **anon public key** (длинный ключ в блоке `Project API keys` с пометкой `anon public`)
3. Откройте в проекте файл `.env.local` и укажите их:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project-ref.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-public-key-here
```

После этого сайт ApsnyGO будет подключен к вашей базе данных!
